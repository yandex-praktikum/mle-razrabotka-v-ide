# DataFrameReporter: Инструмент первичной диагностики данных

Проект автоматизирует рутинный этап первичного разведочного анализа данных (EDA) с помощью переиспользуемого класса `DataFrameReporter`.

## Какую проблему решает проект

При регулярной работе с новыми датасетами аналитики тратят значительное время на повторение одних и тех же базовых проверок. Класс `DataFrameReporter` задает единый корпоративный стандарт первичного аудита:
- Автоматически определяет размерность таблицы (число строк и столбцов).
- Находит полные дубликаты и рассчитывает их относительную долю.
- Выводит сводные описательные статистики (`describe`) для числовых или всех признаков.
- Анализирует объем и долю пропущенных значений по всему набору данных.
- Поддерживает гибкую настройку формата отображения вещественных чисел и процентов.

## Развертывание и установка окружения

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/kotovski000/mle-razrabotka-v-ide.git
   cd mle-razrabotka-v-ide
   ```

2. Создайте и активируйте виртуальное окружение:
   - **macOS / Linux:**
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
   - **Windows:**
     ```bash
     python -m venv venv
     .\venv\Scripts\Activate.ps1
     ```

3. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Разместите исходный датасет `payments.csv` в директории `data/`.

## Запуск отчета

Для формирования базового отчета по датасету запустите точку входа командой:

```bash
python3 main.py
```
*(или `python main.py` для Windows)*.
